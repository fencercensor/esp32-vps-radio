# تجهيز السيرفر

الدليل مناسب لاستضافة Linux تستخدم Apache أو LiteSpeed وPHP، بشرط السماح بالعمليات الطويلة و`proc_open`.

## مكونات مجلد server

- `admin.php`: لوحة إدارة المحطات وتعيين كلمة مرور الإدارة أول مرة.
- `config-store.php`: قراءة الإعداد والتحقق منه وحفظه بطريقة ذرية.
- `device-config.php`: قائمة خفيفة يقرأها ESP32.
- `gateway.php`: تشغيل FFmpeg وإرسال الصوت المتحوّل إلى ESP32.
- `api.php`: إخراج الإعداد الفعال بصيغة JSON.
- `health.php`: فحص جاهزية FFmpeg و`proc_open`.
- `data/.htaccess`: يمنع تحميل ملفات البيانات مباشرة من الويب.
- `.user.ini`: يعطل buffering والضغط ويزيل حد زمن السكربت عند دعم الاستضافة لذلك.

## 1. رفع الملفات

أنشئ مجلدًا مثل:

```text
/path/to/domain/esp-radio
```

وارفع محتويات `server/` إليه. لا ترفع ملفات إعداد حقيقية من جهاز آخر ولا أي ملف `admin.json`.

## 2. تجهيز FFmpeg

المستودع لا يرفق Binary. ثبّت FFmpeg من مدير الحزم في السيرفر أو حمّل نسخة Static من مصدر موثوق، ثم ضع الملف التنفيذي هنا:

```text
server/bin/ffmpeg
```

واجعله قابلًا للتنفيذ:

```bash
chmod 755 server/bin/ffmpeg
```

تحقق من المصدر والتوقيع أو الـChecksum قبل تشغيل أي Binary يتم تنزيله.

## 3. الصلاحيات

إعداد مبدئي شائع:

```bash
chmod 750 server/data
chmod 640 server/data/.htaccess
chmod 644 server/*.php server/.user.ini
```

قد تختلف الصلاحيات حسب مستخدم PHP وطريقة إعداد الاستضافة. المهم أن PHP يستطيع الكتابة داخل `data/`، وألا يستطيع الزائر تحميل محتويات هذا المجلد.

## 4. أول دخول للوحة الإدارة

افتح:

```text
https://YOUR-DOMAIN.example/esp-radio/admin.php
```

إذا لم يوجد `data/admin.json` ستطلب الصفحة إنشاء كلمة مرور. اختر كلمة مرور طويلة وفريدة. الخادم يحفظ Hash فقط، ولا يحفظ كلمة المرور الصريحة.

بعد الدخول يمكنك:

- إضافة محطة أو حذفها.
- ترتيب المحطات.
- تعطيل محطة مؤقتًا.
- وضع عدة روابط احتياطية للمحطة بالترتيب.

كل حفظ يرفع رقم الإصدار؛ جلسة البث القديمة تُغلق ويعيد ESP32 الاتصال بالإعداد الجديد.

## 5. اختبار الخدمة

افتح:

```text
https://YOUR-DOMAIN.example/esp-radio/health.php
```

النتيجة السليمة تحتوي `"ok": true`. إذا كانت `false` راجع مكان FFmpeg وصلاحيته ودعم `proc_open`.

لاختبار محطة:

```text
https://YOUR-DOMAIN.example/esp-radio/gateway.php?station=cairo
```

هذا رابط صوت طويل؛ لا تستخدمه للاختبار المتكرر إذا كانت الاستضافة تفرض قيود CPU أو عدد عمليات.

## 6. مستوى الصوت

`gateway.php` يحوّل الصوت إلى Mono IMA-ADPCM بدون `volume` أو `alimiter` أو أي رفع `+3 dB`. مستوى المصدر يصل طبيعيًا، ثم يتحكم ESP32 في الخفض من مقاومة `GPIO34`.

## 7. ملف الإعداد

يمكنك نسخ `data/radio-config.example.json` إلى `data/radio-config.json` كبداية، أو تركه غير موجود وإنشاء الإعداد من القيم الافتراضية ولوحة الإدارة. ملف التشغيل الحقيقي متجاهل في Git لأنه قد يحتوي روابط خاصة.

## 8. حماية إضافية موصى بها

- استخدم HTTPS للوحة الإدارة.
- استخدم كلمة مرور قوية وفريدة ولا تحفظها داخل المستودع.
- يمكنك إضافة حماية ثانية للمجلد من لوحة الاستضافة أو تقييد الوصول إلى `admin.php` حسب IP.
- لا تضع لوحة الإدارة خلف Cache عام.
- راقب استهلاك CPU والذاكرة؛ كل مستمع يشغّل عملية FFmpeg مستقلة في التصميم الحالي.
- لا تسمح لشخص غير موثوق بإضافة روابط؛ FFmpeg سيجلب الروابط من شبكة السيرفر.
- حدّث PHP وFFmpeg ونظام الخادم باستمرار.
